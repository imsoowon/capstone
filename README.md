# 캡스톤디자인 — LLM 멀티 에이전트 기반 가상 도시 마케팅 시뮬레이션

한국형 인구 통계 페르소나 데이터로 **가상 주민**을 만들고, 이들을 독립된 **LLM 에이전트**로
구동해 소비·마케팅 상황에서의 행동과 상호작용을 시뮬레이션하는 캡스톤 프로젝트입니다.

## 📅 주차별 진행

| 주차 | 주제 | 내용 | 폴더 |
|------|------|------|------|
| **Week 01** | Nemotron-Personas-Korea EDA | 한국형 페르소나 데이터셋 탐색적 분석 + 최애주민(인상훈) 선정 | [`week1/`](week1/) |
| **Week 02** | 페르소나 멀티에이전트 시뮬레이션 | 최애주민 3인의 캐릭터화 + 롯데시네마 상황에서 대화·협상·합의 시뮬레이션 | [`week2/`](week2/) |
| **Week 03** | 라이브 무대 웹 시각화 | 세 주민이 롯데시네마 로비에서 걷고 대화하며 영화를 고르는 과정을 웹 페이지로 시각화 | [`week3/`](week3/) |

## 🧰 기술 스택

Python · Google Colab · Hugging Face Transformers(Qwen2.5-3B) · 상용 LLM API(Gemini/OpenAI/Anthropic) · SVG/HTML

## 📌 프로젝트 개요

- **Week 01**에서 Nemotron-Personas-Korea 데이터를 분석해 실제 인구 분포에 기반한 가상 주민 후보를 도출하고, 대표 페르소나를 선정했습니다.
- **Week 02**에서는 선정한 세 주민(전기태·이다연·인상훈)을 4방향 캐릭터로 시각화하고, 이들을 LLM 에이전트로 만들어 롯데시네마에서 "함께 볼 영화 한 편"을 합의하는 과정을 시뮬레이션했습니다. 각 페르소나가 성격·말투에 맞게 반영되는지, 에이전트끼리 유의미하게 소통하는지를 검증합니다.

각 주차 폴더의 `README.md`에 상세 내용이 있습니다.
