## 🧩 시뮬레이션 구조

1. **페르소나 정의** — 성격/말투/말버릇/관심사/행동경향/영화관 성향
2. **무대(환경)** — 롯데시네마: 상영작·상영관·가격·매점·예매수단
3. **액션** — `검색한다` / `방문한다` / `구매한다` / `대화한다`
4. **시뮬 루프** — 인상훈→전기태→이다연 순, 공유 로그로 서로의 말에 반응하며 협상
5. **최종 투표** — 각자 한 표 → 만장일치/다수결로 합의 도출
6. **평가** — 심사 LLM이 인물별 반영도(1–5) · 소통 유의미성(1–5) · 합의결과 채점

3B 대응으로 JSON 파서 강건화, 한국어 전용 후처리(언어 누수 차단), 행동 반복 방지,
입장 고수 지침 등을 적용했습니다.

## 📊 결과 요약 (로컬 3B 예시)

- 세 주민이 서로 이름을 부르며 영화 취향을 **설득·협상**
- 최종 투표에서 **다수결로 합의 도출** (예: '고요한 파도' 2/3표)
- 페르소나 반영도: 인상훈·이다연 4~5, 전기태 3~4 / 소통 유의미성 3

한계로 3B는 상용 대비 사투리·일관성이 다소 흐리며, 이는 상용 API와 비교 시 드러나는 지점입니다.
