# Week 03 — 라이브 무대 (웹 시각화)

지금까지 만든 **캐릭터 + 대화 + 액션**을 하나의 웹 페이지로 시각화했습니다.
세 주민이 롯데시네마 로비로 **걸어 들어와**, 말풍선으로 **대화**하고,
검색·방문·구매 같은 **액션**을 이모트로 표현하며 "함께 볼 영화"를 정하는 과정을 보여줍니다.

## 🔗 라이브 데모

**https://imsoowon.github.io/capstone/week3/cinema_stage.html**

> 페이지에서 **▶ 데모 재생**을 누르면 API 키 없이 바로 재생됩니다.

## ▶ 실행 방식

| 모드 | 설명 | 준비물 |
|------|------|--------|
| **데모 재생** | 녹화된 협상(고요한 파도 합의)을 애니메이션으로 재생 | 없음 |
| **실시간 실행** | 브라우저에서 직접 LLM 호출해 매번 새 협상 생성 | Gemini/OpenAI/Anthropic 키 |

## 🎬 구현

- **단일 HTML 파일** (`cinema_stage.html`) — 별도 서버·빌드 불필요
- **SVG 캐릭터** — 팔·다리를 분리해 걷기 사이클, 통통 튀는 idle, 말할 때 점프, 눈 깜빡임
- **영화관 로비 배경** — 상영작 3편 포스터, 조명, 붉은 카펫, 매표 카운터, LOTTE CINEMA 마퀴
- **연출** — 말풍선(속마음+대사) 팝, 액션 이모트/파티클, 지목당한 주민 반응(❗)
- **시뮬 로직** — 노트북과 동일한 페르소나·환경·파서·한국어 필터·최종 투표를 JS로 이식
- **실시간 LLM** — Gemini/OpenAI/Anthropic를 브라우저에서 직접 fetch

## 📁 파일

| 파일 | 설명 |
|------|------|
| `cinema_stage.html` | 라이브 무대 웹 페이지 (전부 이 한 파일) |

## ⚠️ 주의

실시간 실행은 브라우저 직접 호출이라 **API 키가 노출**됩니다.
키는 페이지에서 실행할 때만 입력하고, 파일·커밋에는 넣지 마세요(데모는 키 불필요).
