# 홍대입구역(홍대) 상권 가상인간 방문 시뮬레이션

서울시 상권분석서비스(길단위인구) 데이터를 기반으로 **홍대입구역(홍대) 상권**을 선택하여, 실제 유동인구 분포를 정답표(ground truth)로 삼고 가상인간(Nemotron-Personas-Korea) 에이전트의 방문 시뮬레이션 결과가 이와 얼마나 일치하는지 검증한 프로젝트입니다. 공군호텔 상권 버전과 완전히 동일한 파이프라인·검증 방식을 사용하며, 대상 상권과 매장 라벨링만 교체했습니다.

> **상권명 정정**: 처음에는 "홍대 관광특구"로 이름 붙였으나, 실제 CSV(`서울시_상권분석서비스_길단위인구-상권_.csv`, 34,633행)를 확인한 결과 이 데이터셋의 '관광특구' 구분에는 홍대가 없었다(관광특구는 강남마이스·잠실·종로청계·동대문패션타운·명동남대문북창동다동무교동·이태원 6곳뿐). 홍대 관련 상권은 '발달상권'(홍대입구역·연남동·상수역·서교동)과 '전통시장'(홍대 걷고싶은 거리 등)으로 분류되어 있어, 그중 유동인구 규모가 가장 크고 '홍대 상권'의 핵심부에 해당하는 **홍대입구역(홍대)**(발달상권, 상권코드 3120103)을 최종 대상으로 확정했다.

## 1. 실험 설계

### 대상 상권 선정
서울시 상권분석서비스 길단위인구 데이터(34,633행)에서 **홍대입구역(홍대)**(상권코드 3120103, 발달상권, 서울 마포구 홍대입구역 9번 출구·걷고싶은거리 일대)를 선택했다. 대학가·클럽/공연 문화가 중심인 젊은 층 밀집 상권이라는 점에서 공군호텔(근린상권)·잠실 관광특구(대형 쇼핑 관광특구)와는 또 다른 성격을 가진다.

### 가상인간 에이전트 / 방문 판단 방식 / 방문자 풀 채우기 / 시간대 배정
공군호텔·잠실 버전과 완전히 동일한 방법론을 사용한다.
- nvidia/Nemotron-Personas-Korea에서 10만 명을 무작위 샘플링해 에이전트 풀로 사용
- 방문 판단은 정답표를 참고하지 않고, 나이·페르소나 텍스트(활동성 키워드)만으로 규칙 기반 방문확률을 계산 + Qwen2.5-3B-Instruct로 샘플 100명 검증
- 목표 방문자 수 = 에이전트 풀의 방문확률 합(기대값)으로 설정, 베르누이 시행으로 방문자 확정
- 시간대는 페르소나에 정보가 없으므로 연령대별 상식적 가정으로 확률 배정

## 6. LLM(3B 로컬) 샘플 검증

| 항목 | 값 |
|---|---|
| 샘플 수 | 100 |
| 규칙기반 YES | 8 |
| LLM YES | 0 |
| **규칙기반-LLM 일치율** | **92.0%** |

혼동행렬을 보면 규칙기반이 YES로 판단한 8명에 대해서도 LLM은 전원 NO로 판단해, "방문 안 함(NO)"에서만 두 방식이 일치했다(92/100). 규칙 기반의 평균 방문확률 자체가 낮다 보니(임계값 0.5를 넘는 사람이 8명뿐) LLM도 이와 비슷하게 전반적으로 보수적인 판단을 내린 것으로 보이며, 두 방식 모두 "적극적으로 방문한다(YES)"고 판단하는 경우는 드물었다.

## 8. 결론

### 무엇이 잘 재현되었는가
**성별(MAE 2.55%p)**은 상당히 잘 재현되었다. 이는 방문 확률 계산에 성별 가중치를 의도적으로 배제하여, 시뮬레이션 결과가 자연스럽게 에이전트 풀의 성비를 따라간 결과다.

### 무엇이 재현되지 않았는가
**연령대(MAE 10.94%p, r=0.314)**는 홍대의 가장 뚜렷한 특징인 "20대 쏠림"(42.0%)을 전혀 따라잡지 못했다(시뮬 22.6%). 페르소나 기반 규칙이 20대에게 부여하는 가중치가 실제 상권의 극단적인 편중에 비해 너무 완만했던 것으로 보인다.

**시간대(MAE 4.87%p, r=0.277)**도 재현에 실패했다. 저녁(17-21시) 1위라는 큰 틀은 맞혔지만, 홍대 특유의 심야(00-06시) 유동인구(18.6%, 2위)를 전혀 예측하지 못했다(시뮬 4.6%). 페르소나 텍스트에는 활동 시간대 정보가 담겨 있지 않아, 상식적 가정(젊은 층은 저녁 활동)만으로는 이 상권의 심야 유흥 패턴까지 포착할 수 없었다.

### 종합 판단
공군호텔·잠실 버전과 마찬가지로 **성별 > 시간대 > 연령대** 순으로 재현 정확도가 나타났는데(이번엔 시간대가 연령대보다 오차가 작았다), 이는 홍대라는 상권이 유독 특정 연령대(20대)에 극단적으로 쏠려 있어서 완만한 나이 가중치로는 그 편차를 따라가기 어려웠기 때문으로 해석된다. LLM(3B) 검증에서는 규칙 기반과 92.0%의 일치율을 보였는데, 다만 LLM이 YES로 판단한 사례가 단 한 건도 없어(0/100) 로컬 소형 모델이 전반적으로 더 보수적으로 판단하는 경향을 확인했다.

### 매장 지도에 대한 추가 소견
홍대입구역(홍대)은 공군호텔 상권과 마찬가지로 요구된 8개 업종 중 일부(면세점·테마파크·백화점)가 실제로 존재하지 않는 상권이다. 반면 잠실 관광특구는 8종이 모두 실재했다. 세 상권을 비교하면, 상권의 성격(쇼핑 중심 vs 문화·유흥 중심)에 따라 업종 구성이 근본적으로 다르게 나타난다는 점을 알 수 있다.

### 상권명에 대한 추가 소견
애초 "홍대 관광특구"로 부르려 했으나, 실제 데이터에는 그런 명칭의 관광특구가 없었다. 이는 "관광특구"라는 이름이 실제로 문화체육관광부·지자체가 법정 지정한 좁은 의미의 행정구역인 반면, 일상적으로 "홍대 상권"이라 부르는 지역은 그보다 넓고 여러 개의 하위 상권(발달상권·전통시장·골목상권)으로 쪼개져 관리된다는 점을 보여준다.
