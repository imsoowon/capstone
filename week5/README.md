# 홍대입구역(홍대) 시뮬레이션 v2 — 오차 보정 결과 (코랩 실행 완료)

week4(`hongdae_simulation.ipynb`) 결과를 논문에 쓰기 위해 재검토하며 발견한 해석상 모순을 바로잡고, 오차가 컸던 연령대·시간대 방문확률 가중치를 raking(post-stratification) 방식으로 재설계해 `hongdae_simulation_v2.ipynb`를 코랩에서 재실행했다. 아래는 그 실측 결과다.

## 1. 해석 프레임 수정 (week4 → week5)

| 항목 | week4 서술 | week5 수정 |
|---|---|---|
| 성별 MAE | "잘 재현됐다"는 모델 성공 사례로 제시 | 가중치를 아예 부여하지 않았으므로, 이 오차는 모델의 재현력이 아니라 에이전트 풀의 인구통계 대표성 확인(sanity check)으로 해석. 실제로 이번 재실행에서 3.53%p로 소폭 상승했는데, 이는 가중치가 없는 축이라 매 실행마다 순전히 표본추출 변동(노이즈)에 좌우된다는 방증이기도 하다 |
| 대표 지표 | 세 축 평균 MAE(6.12%p)를 성과 지표로 제시 | 성별을 제외한 연령대·시간대 MAE만 "모델링 성능" 지표로 제시 |
| LLM 검증 | 단순 accuracy(92.0%)만 제시 | precision/recall/F1을 추가해 클래스 불균형으로 인한 착시를 제거 |
| 매장 순위 해석 | 롯데마트 1위를 "고령층 선호 반영"으로 단정 | 연령 분포 왜곡이 줄어든 이번 버전에서 재계산해 확인 (아래 6절) |

## 2. 방법 변경: raking 보정

week4에서 관측된 오차(truth/sim 비율)를 보정계수로 역산해 연령대별·시간대별 방문확률에 곱했다.

- 연령대: 20대 ×1.86, 30대 ×0.88, 40대 ×0.55, 50대 ×0.42, 60대+ ×0.33, 10대는 이론상 ×9.375이 필요하나 Nemotron 풀 자체의 10대 표본 부족으로 ×4.0 상한
- 시간대: 00-06시 ×4.0 상한(이론상 ×4.043), 나머지 시간대는 관측 비율대로 보정. 페르소나에 '클럽·유흥·야간·회식·술자리·파티·나이트' 키워드가 있으면 00-06시 확률을 추가로 1.8배 상향

## 3. 실험 설정 (재실행)

| 항목 | week4 | week5 |
|---|---|---|
| 에이전트 풀 | 100,000 | 100,000 |
| 평균 방문 확률 | 0.30 내외 | 0.267 |

수락률이 오른 건 raking 보정이 20대·심야 확률을 끌어올린 만큼, 전체 평균 확률 분포의 꼬리(고확률 구간)가 두꺼워졌기 때문이다.

## 4. 오차(MAE) 비교: week4 vs week5

| 축 | week4 MAE | week5 MAE | 변화 |
|---|---|---|---|
| 성별 | 2.55%p | 3.53%p | +0.98%p (가중치 없는 통제축 — 노이즈) |
| 연령대 | 10.94%p | 6.23%p | −4.71%p |
| 시간대 | 4.87%p | 1.01%p | −3.86%p |
| (참고) 3축 평균 | 6.12%p | 3.59%p | −2.53%p |

상관계수(r)도 함께 확인했다.

| 축 | week4 r | week5 r |
|---|---|---|
| 연령대 | 0.314 | 0.830 |
| 시간대 | 0.277 | 0.980 |

시간대는 MAE 1.01%p, r=0.980으로 사실상 실제 분포를 거의 그대로 재현했다. 연령대도 MAE가 절반 가까이 줄고 상관계수가 0.314→0.830으로 크게 개선됐지만, 10대(실제 15.0% vs 시뮬 3.0%, 오차 12.1%p)에서는 여전히 큰 잔차가 남는다 — 이는 앞서 예상한 대로 10대 보정계수 상한(4.0)의 한계이자, Nemotron-Personas-Korea 풀 자체의 10대 표본 부족이라는 구조적 한계로 해석한다.

## 5. LLM(3B 로컬) 샘플 검증 — precision/recall 추가

| 지표 | week4 | week5 |
|---|---|---|
| 샘플 수 | 100 | 100 |
| 규칙기반 YES | 8 | 11 |
| LLM YES | 0 | 1 |
| Accuracy | 92.0% | 90.0% |
| Precision | (미측정) | 1.0 |
| Recall | (미측정) | 0.091 |
| F1 | (미측정) | 0.167 |

Accuracy만 보면 오히려 92.0%→90.0%로 떨어진 것처럼 보이지만, precision/recall을 보면 이야기가 다르다. LLM이 YES라고 판단한 유일한 1건은 규칙기반도 YES로 판단해 precision 1.0(LLM이 YES라고 하면 틀리지 않음)이지만, 규칙기반 YES 11건 중 LLM이 동의한 건 1건뿐이라 recall은 0.091로 매우 낮다. 즉 규칙 기반이 LLM보다 훨씬 관대하게(YES를 많이) 판단하는 경향이 이번에도 확인됐다 — week4의 "92% 일치"라는 단일 숫자로는 드러나지 않았던 이 비대칭성이 이번 지표 개선으로 명확해졌다.

week4에서는 롯데마트(고령층 선호 매장)가 1위였는데, week5에서는 엔제리너스(카페)가 1위로 바뀌었다. 매장별 연령 구성을 보면 엔제리너스(20대 42.9%)·세븐일레븐(42.1%)·롯데시네마(42.7%) 등 20대 비중이 높은 매장들이 상위권에 올라왔고, 롯데마트는 5위로 내려갔다. 이는 연령대 시뮬레이션이 실제 분포(20대 42%)에 더 가까워지면서, 매장 선호 로직이 반영하는 "20대가 많이 가는 매장"이 실제로 방문 집계 1위로 이어졌다는 뜻이다 — week4의 매장 순위 해석이 왜곡된 연령 분포 위에서 계산됐다는 한계 지적이, week5 재계산으로 실증적으로 확인된 셈이다.

## 7. 결론

- 연령대·시간대 오차가 크게 줄었다 — 특히 시간대는 사실상 실제 분포를 재현하는 수준(r=0.980)까지 도달했다.
- 10대 구간은 여전히 큰 잔차가 남는다 — 보정계수 상한과 Nemotron 풀의 10대 표본 부족이 원인으로 추정되며, 이는 방법론적 한계로 논문에 명시할 필요가 있다.
- LLM 검증에서 precision/recall을 분리하니 규칙기반의 관대한 판단 경향(낮은 recall)이 명확히 드러났다 — accuracy 단일 지표로는 가려졌던 부분이다.
- 매장 순위가 연령 분포 보정과 함께 실제로 바뀌었다 — week4 해석의 한계 지적이 재실행으로 검증된 사례.
- 성별 MAE는 소폭 상승(2.55→3.53%p)했지만, 가중치 없는 통제축이므로 이는 모델 성능 저하가 아니라 표본추출 노이즈로 해석한다.
