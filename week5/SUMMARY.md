# SUMMARY — 홍대 시뮬레이션 v2 (오차 보정, 코랩 실행 완료)

## 무엇을 했나
week4 결과를 논문에 쓰기 위해 재검토하며 해석상 모순(성별 MAE를 모델 성공으로 서술한 점, LLM accuracy가 클래스 불균형으로 착시인 점, 매장 순위 해석이 왜곡된 연령 분포 위에서 계산된 점)을 먼저 바로잡았다. 이어서 week4에서 관측된 오차를 보정계수로 역산하는 raking(post-stratification) 방식으로 연령대·시간대 방문확률 가중치를 재설계하고, 코랩에서 재실행했다.

## 핵심 결과: MAE 비교

| 축 | week4 | week5 | 변화 |
|---|---|---|---|
| 성별 | 2.55%p | 3.53%p | +0.98%p (가중치 없는 통제축 — 노이즈) |
| 연령대 | 10.94%p | 6.23%p | −4.71%p |
| 시간대 | 4.87%p | 1.01%p | −3.86%p |

상관계수: 연령대 r 0.314→0.830, 시간대 r 0.277→0.980

## 방법
- 연령대 raking 보정: 20대 ×1.86, 60대+ ×0.33 등 (10대는 이론상 ×9.375 필요하나 풀의 10대 표본 부족으로 ×4.0 상한)
- 시간대 raking 보정: 00-06시 ×4.0 상한 + 심야 유흥 키워드 시 추가 1.8배
- LLM 검증에 precision(1.0)/recall(0.091)/F1(0.167) 추가 → 규칙기반이 LLM보다 훨씬 관대하게 YES 판단한다는 비대칭성을 accuracy 단일 지표보다 명확히 드러냄

## 부수 효과: 매장 순위 변화
연령 분포가 실제에 가까워지면서 매장 1위가 롯데마트(고령층 선호) → 엔제리너스(20대 중심 카페)로 바뀜. week4의 "매장 순위 해석이 왜곡된 연령 분포 위에서 나온 결과"라는 한계 지적이 재실행으로 실증됨.
