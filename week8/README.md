## 1. 보정·판정 방법 (서연 방식)

| 단계 | 담당 | 이 페이지에서 |
|---|---|---|
| 누가·언제 상권에 있나 | **실제 데이터** | 연령·성별은 길단위인구-상권(2026 2분기) 비율, 시간대는 편의점 실제 결제 비중으로 에이전트를 뽑고, 조건이 맞는 Nemotron 페르소나를 붙인다(항목 간 독립 가정) |
| 편의점에 들를 성향 | 1단계 규칙 (상대값) | 연령 가중치 × 편의점 키워드 × 방문성향 키워드. 누가 더 많이 오는지의 비율만 정한다 |
| 어느 편의점으로 가나 | **규칙 + 실제 지도** | 허프 모델: 매력도 × exp(−보행 최단거리/λ), λ = 200m. OSM 보행 그래프 최단경로 |
| 방문수·매출 | **실제 데이터** | 시간대별 보정계수 k_t로 BASE를 실제 결제 건수에 맞추고, 시간대별 실제 객단가를 곱한다 |

```
k_t        = 실제 편의점 결제 건수_t ÷ Σ(시간대 t 에이전트의 이용 성향 × 상권 안 편의점을 고를 확률)   [BASE: 신규점 없음]
신규점 연 결제 = Σ_t k_t × Σ(이용 성향 × 신규점을 고를 확률)
신규점 연매출 = Σ_t (위 값)_t × 실제 객단가_t
```

- **편의점 선택 집합**
  - 경계 안 OSM 편의점 30곳
  - 서울시 점포 수(48.5)에서 모자라는 **19곳을 상권 안 도로에 가상 배치**
  - 경계 밖 OSM 편의점 51곳(상권 밖으로 나가는 결제)
- **신규점 효과의 해석**: 신규점은 같은 사람·같은 동선에 점포 하나만 더한 결과입니다. 상권 전체 편의점 수요는 늘지 않는다고 가정했으므로(서연 님과 같음), 신규점 매출은 기존 점포 몫을 나눠 가져온 것입니다.
- **민감도 분석(500회)**: 아래 값을 동시에 무작위로 바꿉니다.
  - λ 120–350m
  - 신규점 매력도 0.67–1.5배
  - 역 출입구 출발 비율 30–70%
  - 미등록 점포 배치(균등 / OSM 편의점 150m 안 집중)
  - 에이전트 복원추출
- **검증**(보정 전 BASE 이용 구성 vs 실제 편의점 결제 구성, MAE %p): 연령 3.1 · 성별 2.8
  - 시간대는 결제 비중으로 에이전트를 뽑았기 때문에 검증에서 뺐습니다.
- **시간대별 보정계수 k_t**(에이전트 1,000명 기준, 이용 1단위당 연 결제 건수): 00–06 7,290 · 06–11 6,516 · 11–14 7,372 · 14–17 7,040 · 17–21 7,717 · 21–24 6,839

### 시간대를 결제 비중으로 뽑은 이유

길단위인구-상권의 21–24시 값이 비정상적으로 작습니다(전체의 1.6%, 아래 정답표 주의 참고). 서연 님처럼 유동인구 시간대로 뽑으면 21–24시 에이전트가 거의 없어 k_t가 9만으로 튀었습니다.

k_t는 시간대마다 따로 맞추기 때문에, 시간대별 인원 수는 결과를 치우치게 하지 않고 정밀도만 바꿉니다. 그래서 편의점 결제의 시간대 비중으로 뽑았습니다.

## 2. 애니메이션(하루 시뮬레이션)

- 실제 비율로 뽑은 100·200·400명이 모두 상권 안에 있고, 이용 성향에 따라 일부가 편의점에 들릅니다(허프 모델로 점포를 고름). 나머지는 음식점·카페 등으로 걷습니다(시각용).
- 화면의 매번 실행에서 k_t를 다시 계산합니다. 후보에 도착한 1명은 그 시간대의 **실제 하루 결제 k_t/365건**으로 환산됩니다(400명 기준 약 100건 안팎). 그래서 하루 실행 결과는 판정 표의 기대값(하루 약 251~275건) 주변에서 흔들립니다.
- 결과 패널 맨 위에는 선택 후보의 **보정 기대값**(판정 표 기준값)을 함께 보여 줍니다.
- 'CSV ↓' 파일에 페르소나별 시간대·이용 확률·선택 점포·k_t·실제 환산 결제/매출이 들어 있습니다. 피드백 ②의 로그 형식으로 확장할 기준입니다.

## 6. 한계

- **수요 총량 고정**: 신규점이 상권 편의점 수요를 늘리지 않는다고 가정했습니다(서연 님과 동일). 신규점 매출은 기존 점포 몫을 나눠 가져온 값입니다.
- **가정 위치**: 실제 빈 점포·임대료·매장 면적은 반영하지 않았습니다("이 자리에 점포가 있다면"이라는 가정). 사람이 고른 3곳 중의 비교입니다.
- **미등록 점포**: 19곳은 위치·브랜드를 몰라 가상 배치했습니다. 그래서 세븐일레븐 자기잠식은 과소 추정일 수 있습니다.
- **기간 차이**: 매출·점포는 2025년, 유동인구 비율은 2026년 2분기라 기간이 다릅니다. 연령·성별·시간대는 서로 독립이라고 가정했습니다.
- **관광객 누락**: 페르소나는 전국 인구라 관광객·외국인이 없습니다. 홍대의 핵심 수요 일부가 빠져 있습니다.
- **이용 성향의 근거**: 편의점 이용 성향은 1단계 상식 규칙입니다. 서연 님처럼 LLM 판단(이용 여부·품목)으로 바꾸는 것이 다음 단계입니다(피드백 ②와 연결).
- **표시 범위**: 지도에는 OSM 등록 점포만 그립니다. 가상 배치 점포는 이벤트 로그와 CSV에만 나옵니다.

- **개발**: Python(pandas, shapely, pyproj, pyshp, networkx), Playwright/Chromium(브라우저 검증), 순수 HTML/CSS/JS + Canvas 2D
- **라이선스**: OSM(ODbL), 서울시(공공누리 1유형), Nemotron-Personas-Korea(CC BY 4.0), 위성사진(Esri)
